# Security Incident

Declare SEV-1 for credible cross-tenant access or exposed production secrets. Stop affected public intake and outbound alerts through deployment controls; preserve encrypted snapshots and safe logs under restricted incident access. Establish affected time, role, tenant and artifact scope. Revoke sessions/credentials where exposed. Reproduce the failure with synthetic tenant pairs, fix the boundary and add a regression demonstrating both rejection and authorized success. Review all related routes, worker references and foreign keys. An independent reviewer verifies containment and restoration. Privacy/legal owners determine notifications using actual incident facts and applicable agreements. Do not restore traffic merely because an alert stopped firing.
