# Credential Incident

Disable the affected connector immediately in organization controls. The application forgets encrypted credentials and stops intake. Revoke the Stripe App authorization in Stripe; cloud disconnect alone cannot revoke a token at the provider. Rotate developer credentials if their scope was affected. For a webhook-secret incident replace the endpoint secret and expire the compromised old secret at Stripe; ordinary rotation overlap is twenty-four hours, but compromise requires immediate disconnect/reconnect rather than an overlap. For Woo, disconnect on both sides, remove pending signing material and issue a new one-use pairing code. WordPress salt changes invalidate locally encrypted keys. Confirm the replacement key/account/mode, run repair and verify that old signatures and tokens fail. Never paste secrets into tickets.
