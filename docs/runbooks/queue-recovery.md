# Queue Recovery

Inspect DLQ count/age and the authoritative Outbox row using tenant-scoped maintenance tooling. Queue bodies contain opaque references; do not add source payloads. Resolve the handler error first. Reject a queue message whose organization, resource or task differs from its stored intent; never edit it into a trusted command. Use `python manage.py replay_work --organization UUID --work UUID --reason "Reviewed failure and deployed correction"` for an exhausted authoritative row. Replay retains the same intent identity and resets the bounded attempt budget with an audit entry. Observe completion and downstream idempotency before a batch drain. SQS redrive must target the original queue class. An unresolved permanent OAuth failure requires re-consent, not repeated redrive.
