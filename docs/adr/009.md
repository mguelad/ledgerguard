# ADR-009: Allowlisted facts without raw payload retention

Status: Accepted

Source: implementation design v1.0, section 16.2.

## Decision

Normalize at ingress and retain only the fields needed for reconciliation.

## Consequences

Customer names, email addresses, shipping/billing addresses, arbitrary metadata and source payloads are excluded. Account-user email is retained for access and authorized alerts. Safe logs omit raw messages and exception bodies.
