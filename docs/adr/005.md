# ADR-005: Outbound signed WooCommerce plugin

Status: Accepted

Source: implementation design v1.0, section 16.2.

## Decision

Use Ed25519 signed observations, fixed compiled HTTPS origin, Woo CRUD and Action Scheduler.

## Consequences

There is no cloud command endpoint or user-supplied destination. Pairing requires an authorized TLS WordPress session, nonce and one-use code. Host administrators still control their own installation and salts.
