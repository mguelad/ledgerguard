# ADR-004: Stripe App OAuth with read access

Status: Accepted

Source: implementation design v1.0, section 16.2.

## Decision

Use Stripe App OAuth, separate live/test credentials and least read permissions. Merchant-pasted permanent secret keys are not accepted.

## Consequences

The financial reader exposes only approved GET resources. OAuth token operations are the sole provider POST boundary. Uncertain rotating refresh requires renewed consent.
