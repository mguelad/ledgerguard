# ADR-010: AWS EU managed foundation

Status: Proposed

Source: implementation design v1.0, section 16.2.

## Decision

Provide eu-west-1 Terraform for ECS, RDS, SQS, KMS, S3, Cognito, SES and observability.

## Consequences

Confirm pilot residency, procurement, budget and contractual needs before accepting this deployment decision. Separate accounts and keys per environment. Source implementation does not change this decision status.
