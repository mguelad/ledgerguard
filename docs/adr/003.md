# ADR-003: Django 5.2 LTS

Status: Accepted

Source: implementation design v1.0, section 16.2.

## Decision

Use Django 5.2 on Python 3.13 with PostgreSQL 17, strict typing and the current locked security patch.

## Consequences

SSR and established authentication/database tooling reduce custom infrastructure. Review LTS support before its end; dependency updates pass the same security and regression gates.
