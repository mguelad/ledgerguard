# ADR-006: Hybrid event and overlap repair

Status: Accepted

Source: implementation design v1.0, section 16.2.

## Decision

Use hooks/webhooks for latency and overlapping scans for completeness.

## Consequences

Never infer absence from event delivery alone. A scan must finish contiguously; failures invalidate coverage. Thirty-minute overlap and daily thirty-day repair cover ordinary gaps, with bounded initial windows.
